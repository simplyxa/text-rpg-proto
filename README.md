# text-rpg-proto

Минимальный прототип текстовой браузерной RPG.

Запуск локально:

1. Установите Node.js (v16+)
2. Клонируйте репозиторий

   git clone https://github.com/simplyxa/text-rpg-proto.git
   cd text-rpg-proto

3. Установите зависимости и запустите

   npm install
   npm start

4. Откройте http://localhost:3000

Это простой прототип: создание персонажа, перемещение между локациями, простая боевая система и инвентарь.

Дальше можно улучшать: авторизация, БД (Postgres/SQLite), пошаговая боевая система, квесты, магазин, кланы и т.д.
