# text-rpg-proto

Минимальный прототип текстовой браузерной RPG.

Запуск локально:

1. Установите Node.js (v16+)
2. Клонируйте репозиторий

   git clone https://github.com/simplyxa/text-rpg-proto.git
   cd text-rpg-proto

3. Установите зависимости и запустите

   npm install
   npm start

4. Откройте http://localhost:3000

Это простой прототип: создание персонажа, перемещение между локациями, простая боевая система и инвентарь.
Главный экран в мобильном стиле доступен в городе (`/city`) после входа или создания героя.
Страница профиля «Мой герой» доступна по адресу `/character` из главного меню города; для просмотра войдите или создайте героя.

### Игровые системы Sprint 1

- В бою учитываются физический, магический и ядовитый урон, сопротивления, критические удары, уклонение и блок.
- Снаряжение имеет редкость и бонусы; выпадающие предметы могут получать префиксы/суффиксы с бонусами атаки, защиты, здоровья или регенерации.
- Очко таланта выдаётся за каждый новый уровень. Таланты из веток «Натиск», «Выживание» и «Мудрость» улучшаются на странице `/talents`.
- В магазине `/shop` можно покупать снаряжение и продавать ненадетые предметы; цены и проверка золота рассчитываются сервером.

Проверка игровых формул: `npm test`.
